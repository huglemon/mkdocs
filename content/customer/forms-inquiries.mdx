# 表单与询盘

询盘是客户提交的表单数据。后台可自定义表单字段，前台按字段渲染。

## 表单管理

「询盘管理」→「表单管理」：
- 默认表单：姓名、邮箱、公司、电话、留言
- 自定义表单：字段可配置（类型/必填/长度/选项）
- 新建后，在「页面数据」加「表单」块选该表单，前台渲染
- **指派规则**：每个表单可选「不指派（跟随访客粘性 / 站点均分）」或「**轮流分给选定的业务员**」——后者勾选几位业务员，询盘在它们之间按序轮询
- **文件上传字段**：字段类型可设「文件上传」；上传**跟随表单一起提交**，限图片 `jpg/png`、文档 `pdf/xls/xlsx/doc/docx`、压缩包 `zip/rar`，**单文件 ≤ 20MB**，整站有每日上限并按访客 IP 限流

## 业务员管理

「系统配置」→「业务员管理」：

- 业务员身份来自「持站点业务员角色」的成员——先在「成员与授权」给成员挂业务员角色，再回本页填**联系方式**（显示名 / 职位 / 邮箱 / 电话 / WhatsApp / 微信）、**排序**与**状态**（在职 / 休假）。
- **访客保护期**（默认 90 天）：同一访客在保护期内始终归同一业务员。
- 业务员置为「**休假**」后，其名下访客进入**公海**，由管理员手动指派。
- 页面底部「**公海客户**」列出未指派的询盘，可手动指派给某业务员。

## 询盘如何分派

每条询盘按以下优先级自动分派：

| 优先级 | 规则 |
|---|---|
| 1 | **访客粘性**：同一访客之前被分给谁，保护期内一直给谁 |
| 2 | **联系按钮指定**：页面里某个联系按钮绑定了某业务员，则给该人 |
| 3 | **表单指派**：该表单设了「轮流分给几位业务员」，在其中按序轮询 |
| 4 | **站点均分**：以上都没有时，在所有在职业务员之间轮询均分 |
| 5 | **兜底**：没有可用业务员时，落到站点级联系方式（公海），可手动指派 |

> 详情页里的「联系按钮」若绑定了文章/产品的作者，会直接带出该作者的联系方式（优先于访客粘性）。

## 查看询盘

「询盘管理」→「询盘列表」：列表显示基础字段与**指派给谁**，点「查看」弹窗显示完整详情（自定义字段、来源追踪 IP/UTM/UA、Umami 会话）。

## 防重复提交

同 IP + 同内容 60 秒内重复提交提示「请勿重复提交」。

## 状态管理

询盘状态：新询盘/已读/已回复/已归档。可添加备注。
