# 内容管理

后台的内容分为动态内容（文章/产品）与页面静态内容（页面块）。

## 文章

「内容管理」→「文章列表」：新建文章（标题/摘要/正文/封面/分类/作者），发布后前台自动显示。多语言站可逐语言编辑。

### 从微信公众号导入

已在公众号发过的图文可以直接搬进来，不必手抄。

**入口**：文章编辑页顶部「新建文章 / 编辑文章」那一行的**右侧**「导入」（微信图标）→ 粘贴公众号文章链接 → 「开始导入」。

会自动填入：

- **标题**、**封面**、**正文**，以及**正文里的图片**（图片会下载后转存到你的素材库，前台直接显示，不依赖微信）
- **加粗、斜体、下划线**，以及段落的**居中 / 右对齐**
- 公众号里的小标题（转成后端的标题样式）与**表格**

几点说明：

- **链接怎么取**：在微信里打开文章 → 右上角「⋯」→「复制链接」。若提示链接参数不完整，多半是复制方式不对，重新复制一次即可。
- **摘要不会自动填**：公众号文章本身没有摘要字段，需要你自己写。
- **这些排版不保留**：文字颜色、字号大小、字间距（后台编辑器不支持这些格式）。正文里的**视频号 / 音频 / 小程序卡片**也无法导入，需要手动补。
- 若个别图片未能导入，可在编辑器里手动插入。
- 已有正文时点导入会先让你确认——**导入会覆盖当前正文，且不能撤销**。

## 产品

「产品管理」→「产品列表」：新建产品（标题/摘要/主图/详情/分类），发布后前台自动显示。

- **主图 / 轮播图**：并排显示、尺寸一致；约 6 张仍在一行，超出自动换行。
- **权重**：右栏「状态」下方，**数字越大排序越靠前**；**置顶优先于权重**（置顶项永远排最前）。
- **自定义段**（辅助功能）：位于「产品详情」**下方**。按需填写特殊字段 / 属性表等，**具体格式与用法请联系客服确认**。每段有一个「**标识**」（模板据此取用，**仅支持英文字母、数字和下划线**，悬停 `?` 有说明）；三种段——**属性表**（名称/值，可调序）、**富文本**、**图集**（可调序），均按语言保存。

## 删除 = 移入回收站（软删除）

文章和产品的「删除」并不是真正物理删除，而是**移入回收站**：

- 列表页删除按钮 → 二次确认 → 移入回收站
- 已删除内容从正常列表消失
- 前台立即不再展示（公开 API 与详情都排除）
- 可在「回收站」中**恢复**或**彻底删除**

### 回收站

文章和产品列表页顶部都有「回收站」入口：

- **恢复**：内容回到正常列表，保留原发布状态、翻译与关联
- **彻底删除**：二次确认后永久删除主记录、翻译、分类/标签关联（不可恢复）

### 关键语义

```text
正常内容：deletedAt = null
回收站内容：deletedAt != null
公开可见：published 且 deletedAt = null
恢复/彻底删除：只允许回收站中的内容
```

回收站内容不能通过直接 URL 进入编辑页，也不能被翻译或批量操作继续处理。

## 页面数据（块）

「页面管理」→「页面数据」：每个页面由若干块组成。

块类型：纯文字、单图、轮播图、相册、列表、富文本、JSON、文章列表、产品列表、分组容器、表单。编辑块后前台即时刷新。

## 分类与标签

「产品管理 / 内容管理 → 分类 / 标签」：

- **分类**：支持**无限层级**（父分类 + 子分类）；前台按层级侧边栏展示。
- **标签**：扁平，用于内容打标。

分类/标签名称可**多语言翻译**（见下）。

## 翻译（多语言站）

后台对**页面 / 文章 / 产品 / 分类 / 标签 / 作者**统一提供「**翻译到所有语言**」：

- 点按钮 → 确认 → 生成后台任务，显示**进度条**，**可离开页面**；
- 已完整的语言自动跳过；部分失败会给出计数与错误；
- 文章/产品的手动翻译默认**不被自动覆盖**（需要时用「全部重翻（含手动）」，不可撤销）。

### 查看与手改译文（分类 / 标签 / 作者）

每一行的「翻译」弹窗里，除「**确认翻译**」（AI 生成 / 覆盖）外，还有「**编辑现有翻译**」入口——**逐语言查看与修改**；把某语言名称清空再保存 = **删除该语言译文**。

### 周期任务的自动翻译

多语言站的「AI 周期任务」勾选「**直接发布**」时：先生成**草稿** → 逐语言翻译 → **全部语言完成才发布**（翻译没完成，前台看不到这篇文章）；翻译进度在该任务里是一个「**全量翻译**」步骤。

细节见平台手册「后台翻译操作」。

## 素材库

「素材库」上传图片/文件（R2 存储），供文章/产品/页面块引用。

## 导航

「页面管理」→「导航列表」：配置前台顶部导航（内部页/外链/分组两级）。
