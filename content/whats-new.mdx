# 最近新特性与变更

本页汇总 **2026-09-04 之后** 平台（CMS + 模板）上线的能力。每条给出「做了什么修改」和细节文档入口。

## 登录体系：手机号登录 · 手机号绑定 · 短信改密（2026-09-21）

### 登录页改为 Tab 切换（新）
- 「手机号登录」（默认）与「邮箱登录」以 **Tab 切换**，取代原先两套表单上下并列；两个表单的错误提示各自归入所属 Tab（此前邮箱错误挂在页面顶部，切了 Tab 也看得到）。
- `?reset=1`（改密成功回跳）时默认落在邮箱 Tab——否则「请使用新密码登录」的横幅与展示的手机号表单自相矛盾。
- 新增 `components/ui/tabs.tsx`（封装 base-ui Tabs，含 root/list/tab/panel），激活态消费 `data-active`。

### 手机号 + 短信验证码登录（新）
- 阿里云短信通道用**零依赖手写 HMAC-SHA1 签名**实现，未引官方 SDK——其依赖树会拖入 moment / lodash / ws / xml2js 约 20MB，且需要 `serverExternalPackages` + 动态导入，风险只在真 Vercel 部署才暴露。项目已有手写签名先例（`lib/auth/wechat-relay.ts`）。
- 发送语义：**AK + 签名 + 模板四项齐备才真发**；只配 AK 而缺签名/模板**直接报错、不降级 mock**，避免「以为发了其实没发」；mock 仅限本地 dev 打印验证码，**Preview / Production 一律拒绝**（Preview 与生产同库，若走 mock 会把真实用户验证码写进日志）。
- 限流抽到 `lib/auth/otp-guard.ts`：登录/绑定与短信改密**共用同一组 Redis 预算**（同号 1h≤5、同号 60s 冷却、同 IP 1h≤20），否则交替打两个端点即可拿到 2× 短信额度。

### 手机号绑定 / 换绑（新）
- 「右下角头像 → 账号设置」新增手机号区块，走插件内置 `verify({ updatePhoneNumber: true })`（需登录态，不校验旧号）。
- 手机号真值用 `useSession()` 读取——官方 `phoneNumberClient` 注册了 atomListeners，绑定成功后 `$sessionSignal` 会自动刷新。
- **不提供「解绑」**：手机号可能是该用户唯一的登录凭证，解绑会把自己锁死；只支持换绑（新号覆盖旧号）。

### 短信验证码重置密码（新）
- 新增「忘记密码」页，建在插件内置 `requestPasswordReset` / `resetPassword` 上，不自研。注意 `resetPassword` 的字段是 **`otp`**，与登录 `verify` 的 `code` 不同。
- 开 `revokeSessionsOnPasswordReset`：**重置成功后清空该账号全部 session**（否则被窃 session 依然有效）。
- 全程防枚举：手机号未注册也返回成功，前端文案不区分。
- 重置密码页改用 compact 外壳（logo 左上角 + 表单略高于居中），与 404 一致；`BrandShell` 新增 `contentAlign`，登录/注册保持大 logo 居中不变。

### 未绑定手机号不再静默建号（行为变更）
- 此前未绑定的手机号会被插件**静默建出一个零权限空账号**（占位邮箱 `{号}@phone.inwind.local`、无密码、role=user）——既绕过邀请制（`disableSignUp: true`、注册页写着「账号由邀请开通」），用户又被登进一个什么都点不了的后台。
- 现改为：验码通过后发现该号未绑定 → 返回 400 `PHONE_NOT_REGISTERED` → 登录页转入引导步「用邮箱和密码登录并绑定」，并可一键切到邮箱 Tab（切换后显式接管焦点，避免焦点掉到 body）。
- 实现上保留 `signUpOnVerification`，由 `databaseHooks.user.create.before` 在建库前抛 `APIError` 拦下——这样**保住插件内置的验码保护**（`allowedAttempts` 防爆破 / `expiresAt` / 原子消费），无需自定义 `verifyOTP`（那条路会丢掉全部保护）。
- **判断刻意留在验码之后**：内置校验是「先消费再比码」，故「该号未注册」只有持有正确验证码的人才能得知。若把查库前移到验码之前，任何人对任意号码发一个乱码就能读出该号是否注册——那是注册枚举预言机。代码内已加 ⚠️ 注释防止后人「优化」成前置检查。
- 本轮不做自助建号（零权限待授权账号），建号仍走邀请制。

### 修复
- **`Verification` 缺 `updatedAt`**：better-auth 1.6 创建验证码记录时同时写 `createdAt` / `updatedAt`，缺列导致 `send-otp` 在落库阶段 500（且早于 `sendOTP` 回调，故 mock 通道连验证码都不打）。已补列（迁移 `20260921000000`）。
- **限流报错变成 500 空响应体**：守卫抛裸 `Error` 会被 better-auth 折成 500 且 body 为空，客户端拿不到任何提示。改抛 `APIError` → **429 + 可读文案**。
- **登录页验证码字段名错**：`verify` 的字段是 `code`，此前误传 `otp`（官网示例里的 `otp` 属于 `reset-password` 端点）。插件客户端 `$InferServerPlugin` 为 `{}`、不做类型推断，故 TS 不报错、运行时静默 400。
- **库↔schema 漂移收口**（迁移 `20260921010000`）：12 张表的 `updatedAt` 去掉多余的 DB 侧 `DEFAULT`（Prisma 的 `@updatedAt` 始终显式写值，DB DEFAULT 从不生效），并对齐 `Account.providerId` / `Permission.action` / `page_blocks.slug` / `Role.isSystem` / `Site.defaultLocale` 的默认值。

### 运行提示
- **短信通道开通中**：`ALIYUN_SMS_*` 只配在 Vercel **Production**；运营商报备（移动 / 联通 / 电信）仍在进行，**报备通过前即使网络连通也发不出短信**。期间手机号登录与短信改密不可用（公开站「登录与账号」已注明）。
- **跨境网络约束**：`vercel.json` 把函数钉在 **hkg1（香港）**，而 `dysmsapi.aliyuncs.com` 解析到**大陆（张家口）** IP，香港→大陆这条跨境路径实测 **8s 超时**（Vercel 没有大陆区域，这是架构约束而非代码问题）。报备通过后若仍超时，需单独规划出口方案。另：老项目 `cms.inwind.cn` 也在香港，**中转过去同样绕不开这条路径**。
- `ALIYUN_SMS_*` 切勿加 `NEXT_PUBLIC_` 前缀（会打进客户端 bundle 泄露 AK）；改了环境变量须**重新部署**才在 serverless 生效。

## 业务员指派 · 作者翻译 · 产品自定义段（2026-09-19/20）

### 业务员管理与询盘指派（新）
- **业务员管理**：后台「系统配置 → 业务员管理」，给持业务员角色的成员配显示名 / 职位 / 邮箱 / 电话 / WhatsApp / 微信 / 排序 / 状态（在职·休假），并设「访客保护期」（默认 90 天）与「公海」手动指派。
- **询盘自动指派**：按优先级「**访客粘性 → 联系按钮指定 → 表单指派 → 站点均分 → 站点级兜底**」把每条询盘派给业务员；同一访客在保护期内始终同一业务员。业务员置为「休假」时其客户进入公海。
- **表单指派规则**：表单可设「不指派（跟随访客 / 站点均分）」或「轮流分给选定的业务员」。
- 细节：「表单与询盘」。

### 内容作者翻译 + 译文逐语言查看/编辑（新）
- **作者可翻译**：作者名字 / 简介支持多语言，公开 API 按 `locale` 返回本地化作者信息（作者页与文章作者栏一致）。
- **译文逐语言编辑**：分类 / 标签 / 作者每一行点「翻译」→ 弹窗内「**编辑现有翻译**」即可逐语言查看与手改；清空某语言名称再保存 = **删除该语言译文**（与「确认翻译」的 AI 生成分工明确）。
- 细节：「内容翻译体系」「内容管理」。

### 周期任务「直接发布」自动全量翻译（新）
- 多语言站 + 周期任务勾选「直接发布」时：先生成**草稿** → 逐语言翻译 → **全部语言完成才发布**（翻译未完成，前台看不到这篇）；翻译进度是该任务里的「**全量翻译**」步骤。
- 细节：「内容管理」。

### 产品：自定义段 / 权重 / 主图轮播
- **自定义段（辅助功能）**：位于产品详情下方，按需填写特殊字段 / 属性表。每段有语言无关的「**标识**」（模板据此定向取用，**仅支持英文字母、数字、下划线**）；三种段——**属性表**（名称/值，可调序）、**富文本**、**图集**（可调序），均按语言保存。
- **权重**：右栏「状态」下方，**数字越大越靠前**；**置顶优先于权重**（置顶项永远在最前）。
- **主图 / 轮播图**：并排显示、**同尺寸**，约 6 张仍在一行，超出自动换行。
- 细节：「内容管理」「公开 API 参考」。

### 修复
- **AI 任务卡「等待中」**：平台超级管理员发起的任务被误拒、且失败时状态不回写——已补超管旁路 + 失败必回写终态。
- **AI 任务步骤重复**：每步此前落成「执行中 + 完成」两行——已改为单行就地更新。
- **模型按用途不生效**：文章管线的「生成大纲 / 撰写草稿 / 润色优化」曾**一律走 chat 模型**，后台按用途配置的 `outline/draft/polish` 从不生效——已按各自用途解析。
- **编辑器插入图片时页面崩溃**（React #185）：素材弹窗打开触发无限重渲染——已修复。
- **询盘表单文件上传**：上传字段**跟随表单**绑定提交；限格式（图片 `jpg/png`、文档 `pdf/xls/xlsx/doc/docx`、压缩包 `zip/rar`）、单文件 20MB、整站每日上限、按访客 IP 限流。
- 运行提示：AI 相关改动中**跑在 Worker 里的部分需另在 Dokploy 重新部署**才生效（Vercel 生产 promote 不覆盖 Worker）。

## 站点地图与标签（2026-09-18）

- **sitemap 改为全量输出（修复「sitemap 几乎没用」）**：模板 `app/sitemap.ts` 改为「静态路径 + CMS 全量路由清单」，覆盖**每个启用语言**下的**页面 / 产品 / 产品分类 / 文章 / 文章分类 / 产品标签 / 文章标签 / 作者**。产品/文章取「该语言翻译 slug，否则回退本 slug」；分类/标签 slug 语言稳定。此前只有 5 条静态路径、产品只有默认语言，还混入了不该出现的 `/home`——这些均已根治。
- **新增公开端点 `site/sitemap`**：一次性返回上述全量公开路径（按语言）。过滤 draft / 回收站 / 外链 / noindex，页面排除 `pageType=home` 与保留 slug（`about`/`contact`/`products`/`news`/`authors`/`home`）。

- **站点图标**：模板 `app/icon.png` 由 Next 图标文件约定自动接入 favicon，无需改 layout。
- 细节：「多语言基线与 SEO」「列表分页与静态化」「公开 API 参考」

## 构建与部署性能（2026-09-18）

- **函数区域固定香港 `hkg1`（最大提速）**：CMS 与模板此前都跑在 Vercel 默认区域 `iad1`（美东），而自建 PostgreSQL 在香港——**每次查询跨太平洋往返**。同区后单次调用延迟降一个数量级，**客户站点构建 8m27s → 1m18s**，线上请求一并受益。
- **预渲染上限按类型拆分**：`STATIC_PRERENDER_PRODUCTS_LIMIT`（默认 **50**）/ `STATIC_PRERENDER_NEWS_LIMIT`（默认 **20**），超出的长尾走按需 ISR——构建时间**不随内容量线性膨胀**（3000 个产品不会变成 3000 次构建期渲染）。
- **页面全量预渲染（护转化红线）**：后台「页面管理」里的**所有已发布页面**（× 每个语言）无条件预渲染、由 CDN 直出，保证首页 / 导航目标 / 广告落地页「一点即达」；产品与文章仍只预渲染 top-N。
- 细节：「部署与域名」

## 列表与分页

- **改为 canonical 路径分页**：产品/新闻列表从 `?page=` 改为 `/products/page/N`、`/products/category/<slug>/page/N`（新闻对称）。每个页码独立可索引。
- **旧 query 308 迁移**：middleware 把 `/products?page=N`、`/news?category=&page=` 永久重定向到路径分页。
- **标签页**：`/{lang}/products/tag/<slug>`、`/{lang}/news/tag/<slug>`，分页形态同上（`/tag/<slug>/page/N`）。
- **构建期取数重写（修复构建卡死）**：静态参数改为「按分页信封读总页数 + 进程内记忆化 + 有界并发」，替代原先逐条串行 `limit:1000` 全量拉取——后者会让构建 `Collecting page data` 阶段卡住几十分钟。
- 细节：「列表分页与静态化」

## SEO 与结构化数据

- **分类页 / 分页页 TDK 合成**：`/products/category/<x>`、`/news/category/<x>` 及其分页页此前**没有 TDK**（回退到站点名）；现按「分类名 | 站点名（· 页码）」合成标题，`description` 取基础列表页 CMS SEO，canonical/hreflang 沿该页路径。
- **每页 `<html lang>`、canonical、per-page SEO**：`middleware` 解析 locale → root layout 输出 `<html lang>`；静态页与详情页各自的 `generateMetadata`。
- **列表页 TDK 改读后台**：`/`、`/products`、`/news`、`/about`、`/contact` 的标题/描述从后台页面 SEO 读取（`pageMetadata`），不再用模板内置文案。
- **自动生成 JSON-LD**：站点级 `Organization`/`WebSite` + 文章 `Article` / 产品 `Product` / `BreadcrumbList`。
- **站点 logo 设置**：后台「站点设置」上传 logo，公开 API 返回 `logoUrl`；模板按「后台 logoUrl → `public/logo.png` → 空」回退。
- 细节：「多语言基线与 SEO」「结构化数据与站点 logo」

## 内容翻译

- **修复：`list` 块无 `columns` 时漏翻**：部分列表块（如 FAQ）数据里没有列元数据，此前**收集为空 → 原样复制**（表现为「FAQ 块没翻译」）；现按自然语言启发式兜底收集（自动跳过 URL / 纯数字 / 图标名）。
- **修复：页面翻译写入超时**：大页面（30+ 块）此前在默认 **5s 交互事务**里逐个 upsert，远端库下超时回滚 → **整个语言失败**；现改批量事务并显式放宽到 30s。
- **修复：任务卡在「执行中」**：Worker 中途中断后任务**永远 running、无法停止**；现新增**手动强制停止**（清租约，运行中的 worker 下一次心跳即失效停写）与**陈旧任务自动判失败**（心跳超 90s 自动回收，翻译页与任务轮询触发）；内联兜底执行带整批时间预算，到点落 partial/failed 而非被静默 kill。
- **进度归位**：翻译进度**移入翻译确认弹窗**（含「强制停止」按钮），AI 任务页**不再显示翻译任务**。
- **翻译覆盖全类型页面块文本**：`list`（列名 + 文本列单元格）、`carousel`/`gallery`（alt/title）、`single-image`（alt/caption）、`json`（递归自然语言字符串）等**都翻**——早期版本对非 `text`/`html` 块是**原样复制**。
- **SEO 关键词参与翻译**：`keywords` 数组与 `metaTitle`/`metaDescription`/`ogTitle`/`ogDescription` 一并翻译。
- **文章/产品 SEO 落库**：翻译后写入目标语言的 `seoJson`（此前完全不写）。
- **分类/标签可翻译**：新增翻译表 `CategoryTranslation`/`TagTranslation`，公开 API 按 `locale` 返回本地化名称（`slug` 不变）。
- **任务化 + 可离开 + 手动保护**：`AiTask` 驱动，进度条、可离开页面、终态如实（completed/partial/failed）；文章/产品保留手动翻译保护。
- **后台语言与前台解耦**：翻译目标是「前台启用的全部语言」，与录入语言无关。
- **完整性判定如实化**：判定变严后，**对既有内容再点一次「翻译到所有语言」即可自动补翻**漏掉的部分。
- 细节：「内容翻译体系」「页面块调用与渲染」「后台翻译操作」

## 公开 API

- **`site/sitemap`（新）**：全量公开路径清单（页面/产品/分类/文章/标签/作者 × 每个语言），供模板生成 sitemap。
- **`content/tags`（新）**：标签列表（本地化名称，按 `type`）。
- **列表 tag 过滤**：`content/posts`、`content/products` 支持 `tagSlugs`/`tagIds`。
- **文章列表分页信封**：`content/posts` 支持 `response: "envelope"`（`pagination` + 语言元信息），与产品同构。
- **分类树接口**：`content/categories?type=post|product&locale=xx` 返回**分类树**（roots + 递归 children），`name` 按 `locale` 本地化；可选 `parentId`（取该分类的子孙）与 `depth`（限制层数）。
- **预渲染端点**：`site/published-routes`、`site/locale-routes` 供模板生成静态路由与真实翻译路径切换。
- 细节：「公开 API 参考」

## 平台后台与权限

- **模型连通测试按用途分流**：平台「测试」按钮此前**对任何用途都调 chat 接口**，image 用途的模型必然报 400；现 image 走生图端点探针（`{base}/images/generations`，其余仍走 chat）。注意：image 测试会真实生成 1 张最小测试图。
- **Scoped RBAC**：角色/权限/资源范围化，成员按站点与功能授权；CMS 导航与控件按「有效能力」裁剪（无写权限时隐藏/置灰）。
- **分类/标签翻译入口**：后台分类/标签管理新增「翻译到所有语言」（确认 + 进度）。

## 平台运维

- **Prisma 连接池收紧**：每 serverless 实例连接数上限由 10 降到 2，空闲连接 30s 回收，避免共享 PostgreSQL 连接被打满导致全站 500 / 构建期取数卡死。根治仍建议加连接池（PgBouncer）。
- **函数区域固定 `hkg1`**：见上「构建与部署性能」——与自建 PG（香港）同区。
