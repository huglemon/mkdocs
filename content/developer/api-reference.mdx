# 公开 API 参考

客户前台站点通过公开 API 从 Admin 获取内容和提交询盘。所有受保护端点都带 `X-Site-Id` / `X-Site-Secret` 请求头鉴权。

## 鉴权

```text
X-Site-Id: <站点 ID>
X-Site-Secret: <站点密钥>
```

站点密钥在后台站点详情页的「API 凭证」获取。缺少认证信息返回 `401`；密钥不匹配或站点未启用返回 `403`。

## 时间与语言

- API 时间点始终返回 ISO 8601 UTC instant，例如 `2026-09-04T01:00:00.000Z`。
- 前端按自身展示策略格式化时间；不要将 API 时间点当作无时区文本解析。
- 内容接口使用 `locale` 选择语言。无效或未启用的前台语言会回退到站点 `frontendLocale`。
- 产品字段按以下优先级解析：

```text
请求语言翻译 → 默认语言翻译 → 产品主字段
```

## 端点清单

| 接口 | 方法 | 用途 |
|---|---|---|
| `site/settings` | GET | 站点公开设置、语言配置与 logo |
| `site/navigation` | POST | 导航树 |
| `site/published-routes` | GET | 已发布内容清单（静态参数与旧版路由） |
| `site/sitemap` | GET | 全量公开路径清单（页面/产品/分类/文章/标签/作者 × 每个语言），供模板生成 sitemap |
| `site/locale-routes` | GET | 单个资源的真实翻译路径（语言切换） |
| `pages/:slug` | GET | 页面、内容块和 SEO |
| `content/products` | POST | 产品集合（可选分页信封） |
| `content/products/:slug` | GET | 完整产品详情 |
| `content/posts` | POST | 文章集合（可选分页信封） |
| `content/posts/:slug` | GET | 文章详情 |
| `content/categories` | GET | 分类树（本地化名称；可选 `parentId`/`depth` 取子树或限层） |
| `content/tags` | GET | 标签列表（本地化名称；按 `type=post\|product`） |
| `content/authors/:slug` | GET | 作者与文章 |
| `forms/:slug` | GET | 动态表单定义 |
| `inquiry` | POST | 提交询盘 |
| `salesperson/resolve` | POST | 按访客解析业务员（联系按钮 / 询盘指派） |

## 产品集合

```text
POST /api/v1/pub/b2b/content/products
```

### 默认轻量响应

不传 `include` 与 `response` 时，接口保持兼容的轻量裸数组，适合产品卡片、首页推荐和动态产品列表：

```json
[
  {
    "id": "product_1",
    "title": "产品标题",
    "slug": "product-slug",
    "summary": "产品摘要",
    "mainImageUrl": "https://cdn.example.com/product.jpg",
    "publishedAt": "2026-09-04T01:00:00.000Z"
  }
]
```

### 请求参数

```json
{
  "locale": "en",
  "page": 1,
  "limit": 20,
  "categoryIds": ["category_1"],
  "categorySlugs": ["charcoal"],
  "sort": "weight",
  "includeFeatured": true,
  "include": ["gallery", "content", "properties", "categories", "tags"],
  "response": "envelope"
}
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---:|---|
| `locale` | string | 站点前台语言 | 目标语言 |
| `page` | number | `1` | 页码，最小 `1` |
| `limit` | number | `20` | 每页数量，范围 `1–100` |
| `categoryIds` | string[] | `[]` | 当前站点产品分类 ID 筛选 |
| `categorySlugs` | string[] | `[]` | 当前站点产品分类 slug 筛选 |
| `categorySlug` | string | — | 兼容旧版单分类 slug |
| `sort` | string | `weight` | `newest` / `oldest` / `popular` / `weight` |
| `includeFeatured` | boolean | `true` | 是否将置顶产品优先排序 |
| `include` | string[] | `[]` | 显式请求扩展字段 |
| `response` | string | — | 传 `envelope` 返回分页与语言元信息 |

### `include` 白名单

集合接口只允许请求预定义的功能块，不能任意选择数据库字段：

| token | 追加字段 |
|---|---|
| `gallery` | `galleryImages` |
| `content` | `contentHtml` |
| `sections` | `sections`（产品自定义段，见「产品详情」） |
| `properties` | `propertiesJson` |
| `categories` | `categories` |
| `tags` | `tags` |

未知 token、`all`、`*`、负向字段或非字符串数组会返回：

```json
{
  "error": "include 参数无效",
  "code": "INVALID_INCLUDE"
}
```

未请求的扩展字段不会出现。这样列表不会因为一个卡片请求而默认加载全部正文、图册和 taxonomy。

### 请求扩展字段示例

```json
{
  "locale": "en",
  "include": ["gallery", "categories", "tags"],
  "response": "envelope"
}
```

单个产品可能追加：

```json
{
  "galleryImages": [
    {
      "id": "asset_2",
      "url": "https://cdn.example.com/product-2.jpg",
      "alt": "产品侧面",
      "title": "产品侧面",
      "width": 1200,
      "height": 900
    }
  ],
  "categories": [
    { "id": "category_1", "name": "木炭", "slug": "charcoal" }
  ],
  "tags": [
    { "id": "tag_1", "name": "快速燃烧", "slug": "quick-light" }
  ]
}
```

### `response: "envelope"`

为新模板提供真实分页和语言状态，但不破坏旧模板的裸数组契约：

```json
{
  "data": [
    {
      "id": "product_1",
      "title": "产品标题",
      "slug": "product-slug",
      "summary": "产品摘要",
      "mainImageUrl": null,
      "publishedAt": "2026-09-04T01:00:00.000Z"
    }
  ],
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 138,
    "totalPages": 7,
    "hasNext": true,
    "hasPrevious": false
  },
  "meta": {
    "requestedLocale": "en",
    "effectiveLocale": "en",
    "defaultLocale": "zh",
    "fallbackUsed": false
  }
}
```

现有模板若不传 `response`，继续按数组消费即可；新模板可以主动请求 `response: "envelope"`，不再用大 limit 猜测总页数。

## 产品详情

```text
GET /api/v1/pub/b2b/content/products/:slug?locale=en
```

详情接口默认返回完整公开产品视图：

```json
{
  "id": "product_1",
  "locale": "en",
  "contentLocale": "en",
  "fallbackToDefault": false,
  "title": "产品标题",
  "slug": "product-slug",
  "summary": "产品摘要",
  "contentHtml": "<p>产品正文</p>",
  "sections": [
    {
      "id": "sec_1",
      "key": "specs",
      "type": "attributes",
      "title": "规格参数",
      "items": [ { "label": "直径", "value": "33mm" } ]
    }
  ],
  "mainImageUrl": "https://cdn.example.com/product.jpg",
  "galleryImages": [
    {
      "id": "asset_2",
      "url": "https://cdn.example.com/product-2.jpg",
      "alt": "产品侧面",
      "title": null,
      "width": 1200,
      "height": 900
    }
  ],
  "propertiesJson": {
    "diameter": "33mm"
  },
  "categories": [
    { "id": "category_1", "name": "木炭", "slug": "charcoal" }
  ],
  "tags": [
    { "id": "tag_1", "name": "快速燃烧", "slug": "quick-light" }
  ],
  "isFeatured": false,
  "publishedAt": "2026-09-04T01:00:00.000Z",
  "seo": null
}
```

说明：

- `mainImageUrl` 保留用于兼容现有模板。
- `galleryImages` 严格按 CMS 保存的图册顺序返回；主图不会自动插入图册。
- `categories` 与 `tags` 始终为数组；其 `name` 按请求 `locale` **本地化**（译文 → 默认语言译文 → 基名），`slug` 跨语言稳定。
- `sections` 是**产品自定义段**（类型化数组：`attributes` 属性表 / `text` 富文本 / `gallery` 图集）。每段带**语言无关的 `key`（field_name）**，模板据此定向取用（如 `sections.find(s => s.key === "specs")`）；`title`/`label` 按语言本地化，**`key` 不翻译**。目标语言无译文时回退默认语言，均无则为 `null`。列表接口需 `include: ["sections"]`。
- `contentLocale` 表示正文实际来源语言；`fallbackToDefault` 表示当前请求使用了默认语言回退。
- 只返回当前站点、`published` 且未软删除的产品；草稿、归档和回收站产品返回 `404`。
- 主图和图册素材必须属于当前站点且状态为 `active`；失效或跨站点素材会被省略，不会让整个产品请求失败。
- 命中详情后会异步增加浏览量，不阻塞响应。

## 文章集合（分页信封）

```text
POST /api/v1/pub/b2b/content/posts
```

与产品集合同构，支持 `response: "envelope"` 返回真实分页与语言元信息（默认仍是兼容的裸数组）：

```json
{
  "data": [
    {
      "id": "post_1",
      "title": "文章标题",
      "slug": "post-slug",
      "summary": "摘要",
      "coverImageUrl": null,
      "publishedAt": "2026-09-04T01:00:00.000Z",
      "author": { "id": "a1", "name": "...", "slug": "...", "avatarUrl": null, "bio": null }
    }
  ],
  "pagination": { "page": 1, "pageSize": 10, "total": 42, "totalPages": 5, "hasNext": true, "hasPrevious": false },
  "meta": { "requestedLocale": "en", "effectiveLocale": "en", "fallbackUsed": false }
}
```

支持 `locale` / `page` / `limit` / `categorySlug(s)` / `categoryIds` / `sort` / `includeFeatured`。

## 分类树

```text
GET /api/v1/pub/b2b/content/categories?type=post|product&locale=xx&parentId=<id>&depth=N
```

返回**分类树**（根节点数组，子节点递归挂在 `children`），供前台层级侧边栏与 canonical 分类路由消费：

```json
[
  {
    "id": "c1", "name": "木炭", "slug": "charcoal", "sortOrder": 0, "parentId": null,
    "children": [
      { "id": "c2", "name": "速燃木炭", "slug": "quick-light", "sortOrder": 0, "parentId": "c1", "children": [] }
    ]
  }
]
```

### 查询参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `type` | 是 | `post` / `product` |
| `locale` | 否 | 目标语言；缺省站点前台语言。**仅影响 `name`**（本地化） |
| `parentId` | 否 | 只返回**该分类的子孙**（不含该节点自身）。省略 = 返回所有根节点 |
| `depth` | 否 | 只展开 **N 层**（`1` = 只返回直接子级，其 `children` 为空）。省略 = 不限深度 |

规则：

- `name` 按 `locale` **本地化**（`locale` 译文 → 默认语言译文 → 主表基名）；
- `slug` **不本地化**，跨语言稳定（因此 `/products/category/<slug>` 在多语言下是同一路径）；
- `parentId` 必须属于**当前站点 + 同 type**，否则返回 `400`；`depth` 非正整数返回 `400`。

### 只取某分类的直接子级

```text
GET /api/v1/pub/b2b/content/categories?type=product&locale=en&parentId=c1&depth=1
-> [ { "id": "c2", ..., "children": [] }, { "id": "c3", ..., "children": [] } ]
```

### 从某分类起整棵子树（不限深度）

```text
GET /api/v1/pub/b2b/content/categories?type=product&parentId=c1
-> 返回 c1 的子孙（c1 自身不返回），递归到叶子
```

## 标签

```text
GET /api/v1/pub/b2b/content/tags?type=post|product&locale=xx
```

返回标签**扁平列表**（无层级）：

```json
[ { "id": "tag_1", "name": "速燃木炭", "slug": "quick-light" } ]
```

- `name` 按 `locale` **本地化**（`locale` 译文 → 默认语言译文 → 主表基名）；`slug` 跨语言稳定。
- 列表接口 `content/posts` / `content/products` 支持**按标签过滤**：请求体传 `tagSlugs: ["quick-light"]`（或 `tagIds: ["tag_1"]`），与 `categorySlug(s)` 并列。
- 模板据此提供标签页 `/{lang}/products/tag/<slug>`、`/{lang}/news/tag/<slug>`。

## 业务员解析（联系按钮 / 询盘指派）

```text
POST /api/v1/pub/b2b/salesperson/resolve
```

前台「联系按钮」与表单用它把访客解析到**一位业务员**，返回联系方式与 umami 事件名。

请求体：

```json
{
  "visitorKey": "8f0c…-uuid",
  "scene": "product-demo-product",
  "candidateUserIds": ["user_1"],
  "formTemplateId": "form_1"
}
```

| 字段 | 说明 |
|---|---|
| `visitorKey` | 访客稳定标识（UUID）。模板在 middleware 写 **HttpOnly cookie `iw_visitor`**，经自身 `/api/client/*` 代理在**服务端**注入请求，不下发浏览器 |
| `scene` | 场景名（≤40 字），用于 umami 事件名 |
| `candidateUserIds` | 可选。显式候选（如「联系作者」按钮绑定作者） |
| `formTemplateId` | 可选。命中表单若设了「轮流分派」，其候选池参与解析 |

响应：

```json
{
  "source": "salesperson",
  "salesperson": { "id": "user_1", "displayName": "张三", "whatsapp": "+86…", "email": null, "phone": null },
  "contacts": { "email": null, "phone": null, "whatsapp": "+86…" },
  "eventName": "product-demo-product_zhangsan",
  "fallbackFormTemplate": { "id": "form_1", "slug": "default-inquiry" },
  "protectionExpiresAt": "2026-12-18T…"
}
```

- **解析优先级**：访客粘性(1) → 显式候选数组(2) → 表单 sequential 池(3) → 站点全池(4)；无可用时 `source="site"`、`salesperson=null`、`contacts` 为**站点级兜底**（公海）。
- **粘性只受显式候选约束**：联系按钮指定的人会覆盖粘性；表单指派池**不会**夺走粘性访客。
- 同一 `visitorKey` 在**保护期**（默认 90 天）内稳定命中同一业务员。
- `eventName` = `scene_slug`（有业务员）或 `scene`（站点级），供 umami 事件对账。

## 预渲染端点

供前台生成静态路由、sitemap 与真实翻译路径切换：

| 接口 | 方法 | 用途 |
|---|---|---|
| `site/sitemap` | GET | **全量公开路径清单**（见下），模板 `app/sitemap.ts` 用 |
| `site/published-routes` | GET | 已发布内容清单（每条含 `type` / 各语言 `routes` / `lastModified`），静态参数与旧版路由用 |
| `site/locale-routes` | GET | 单个资源的**真实翻译路径**：`?type=product\|post\|author\|page&slug=xxx` → `{ routes: { en, zh, ... }, frontendLocale }`，语言切换器用 |

### `site/sitemap`

```text
GET /api/v1/pub/b2b/site/sitemap
-> { "routes": [ { "type": "product", "routes": { "en": "/en/products/xxx", "zh": "/zh/products/xxx" }, "lastModified": "..." }, ... ] }
```

- 覆盖**每个启用语言**下的 `page | product | product-category | post | post-category | product-tag | post-tag | author`。
- 产品/文章取「该语言翻译 slug，否则回退本 slug」；分类/标签/页面/作者 slug 跨语言稳定。
- 路径为 **internal locale 前缀**（多语言 `/{locale}/...`，单语言 clean），模板再用 `canonicalizePublicPath` 转唯一 public code。
- 过滤 draft / 回收站 / 外链 / `noindex`；页面排除 `pageType=home` 与保留 slug（`about`/`contact`/`products`/`news`/`authors`/`home`）。
- 分类/标签无 `updatedAt`，其 `lastModified` 省略。

## 其余资源

页面、导航、表单、作者等仍保持既有 v1 契约；后续按产品同一原则（默认轻量集合、白名单 `include`、完整详情、显式 locale fallback、安全资源投影）逐步对齐。

> **作者本地化**：`content/authors/:slug` 与文章的 `author` 字段，其 `name` / `bio` 按请求 `locale` **本地化**（`AuthorTranslation`：目标语言 → 默认语言 → 主表）；`slug` 跨语言稳定。

## 缓存

- `GET` 详情接口可结合 ISR/缓存策略。
- `POST` 集合接口通常不进入 Next Data Cache；前台列表页使用 ISR 和内容标签失效。
- 内容更新后由 Admin 触发对应内容标签失效。

## 错误格式

非 2xx 响应包含 `error` 字段。参数校验类错误可能附带稳定错误码，例如：

```json
{
  "error": "include 参数无效",
  "code": "INVALID_INCLUDE"
}
```
