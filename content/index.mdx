# InWind CMS 文档中心

InWind CMS 是一套外贸 B2B 建站系统：通过可视化后台管理内容、表单、询盘与 SEO，前台网站按需渲染，数据即时生效。

## 文档目录

使用左侧侧边栏浏览文档：

- **客户使用指南**：后台内容管理、表单与询盘、SEO 设置
- **模板开发规范**：模板开发、页面块调用渲染、公开 API
- **平台后台手册**：站点管理、部署、域名与语言配置

## 核心能力

- **可视化内容管理**：文章、产品、页面块（文字/图片/列表/表单）后台直接编辑
- **表单与询盘**：自定义表单字段、防重复提交、来源追踪、Umami 会话关联
- **多语言**：默认语言/前台语言/多语言开关由平台配置，前台按需渲染
- **SEO**：每页独立标题/描述/关键词，前台自动生成 meta

## 快速开始

新客户网站由平台开通后，登录后台即可开始管理内容。详见侧边栏对应文档。
