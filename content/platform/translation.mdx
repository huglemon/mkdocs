# 后台翻译操作

平台对**页面、文章、产品、分类、标签**提供统一的「翻译到所有语言」操作。

## 准备：先配好语言

在「站点管理 → 语言配置」确定：

- 后台录入语言（你用哪种语言录入内容）
- 前台默认语言 + **启用语言列表**（翻译的**目标**就是这些前台语言）

> 翻译目标 = **前台启用的全部语言**，与后台录入语言无关——即使录入语言和前台某语言同名，也会产出该语言的前台版本。

## 各内容类型的入口

| 内容 | 位置 | 操作 |
|---|---|---|
| 页面 | 页面管理 → 页面行 | 语言图标 → 确认 → 进度 |
| 文章 | 内容 → 文章列表 → 行尾「…」 | 翻译到所有语言 / 全部重翻（含手动） |
| 产品 | 产品列表 → 行尾「…」 | 翻译到所有语言 / 全部重翻（含手动） |
| 分类 | 分类管理 → 每个分类行 | 语言图标 → 确认 → 进度 |
| 标签 | 标签管理 → 每个标签 | 语言图标 → 确认 → 进度 |

点击后弹出**确认框**（列出目标内容与将发生的事），确认即生成后台任务并**立即返回**。

## 进度与可离开

- 翻译在**后台 Worker** 里执行，页面显示**进度条**；
- **可以离开页面**，任务继续，回来后可在「AI 任务」查看结果；
- 终态如实记录：

```text
已完成   已保存 N 条（+ 跳过 / 失败 / 缺失计数）
部分完成 部分语言成功、部分失败
失败     全部失败（附错误信息）
```

**已完整的语言会自动跳过**（幂等），不重复消耗。

## 手动保护（文章/产品）

- 标记为**手动翻译**的语言版本不会被自动翻译覆盖；
- 需要覆盖时用「**全部重翻（含手动）**」——会从默认语言**重新生成**该内容的全部语言，**不可撤销**。

> 页面没有手动标记，页面翻译会覆盖目标语言（沿用既有语义）。

## 补翻历史内容

完整性判定会比较「标题、SEO、块文本、正文」是否齐全。若某内容是用**早期版本**翻译的（当时漏翻了列表块 / SEO 关键词等）：

**再点一次「翻译到所有语言」即可自动补翻**漏掉的部分——无需人工逐条处理。

## 分类 / 标签

分类与标签的翻译落到**翻译表**（`CategoryTranslation` / `TagTranslation`）：

- 分类：翻译**名称 + 描述**；
- 标签：翻译**名称**；
- 前台按访客语言显示对应译名；**分类 slug 不变**，URL 跨语言稳定。
