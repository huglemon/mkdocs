# 站点管理

平台站点管理（/platform/dashboard/sites）是客户站点的运营中心。

## 创建站点

「站点管理」→「新建站点」：名称（自动生成 slug）、客户组织、域名（可选）、同时创建 Vercel 部署（勾选）、模板分支。

建站后自动创建：站点密钥、默认表单、Umami 网站绑定。

## 站点详情

点进站点详情页，可管理：
- 部署状态：Vercel 进度、预览/正式域名
- 站点状态：草稿/已启用/已停用
- 数据分析：Umami 绑定（自动创建/手动填 ID）
- 语言配置：多语言开关、录入语言、前台语言、语言增删
- API 凭证：站点密钥
- 域名管理：添加/验证/移除
- 设置：站点级键值配置

## Umami 绑定

「数据分析」区块：点「自动创建」在 Umami 建对应网站并回写，或手动填 ID。绑定后前台自动加载统计脚本。

## API 凭证

站点详情页「API 凭证」展示两把运行时密钥：

| 密钥 | 用途 | 浏览器可见 |
|---|---|---|
| SITE_SECRET | 前台请求公开 API 鉴权 | 是（NEXT_PUBLIC 前缀） |
| REVALIDATE_SECRET | 前台 ISR 缓存失效鉴权 | 否（仅服务端） |

两把密钥都支持：

- 默认脱敏，点击显示/隐藏
- 复制
- 成对轮换

轮换会同时生成新的 SITE_SECRET 和 REVALIDATE_SECRET，旧密钥立即失效，并同步到 Vercel env；重新部署后生产环境生效。

> 注意：REVALIDATE_SECRET 是内部缓存控制凭证，用于后台改内容后通知前台刷新 ISR。它没有 NEXT_PUBLIC_ 前缀，浏览器 JavaScript 无法读取。
