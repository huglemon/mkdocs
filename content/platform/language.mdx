# 语言配置

站点语言配置由平台管理（客户后台只读）。

## 配置项（站点详情页「语言配置」）

- 多语言开关：关闭 = 单语言（前台 URL 无语言前缀）；开启 = 多语言（前缀路由）
- 后台录入语言：客户后台编辑内容的语言
- 前台显示语言：访客看到的语言
- 语言增删：从支持语言列表添加/移除

## 生效

语言配置变化 → 前台全站即时刷新（middleware + revalidate）。单语言站前台 URL 无前缀（clean URL），多语言站按前缀路由。

## 客户侧

客户后台「站点设置」只读展示当前语言配置。前台内容按录入语言编辑，按访客语言显示。

## 支持语言

en/zh/zh-CN/zh-TW/fr/de/es/ja/ko/pt/ru/it/ar/nl/tr/vi/th/id/pl。
